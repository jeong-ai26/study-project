# 텍스트 기반 가계부 CLI

한 줄 요약: 텍스트 기반 가계부 CLI 만들기

## 왜 이걸 했는가
- Python 기초를 쌓고자 혼자 해보는 미니 프로젝트를 하기 위함
- Github을 실제로 프로젝트에 사용해 보기 위함

## 무엇을 배웠는가 (핵심 요약)
- Git 초기 세팅 및 사용법을 배웠다.
- csv 모듈에서 reader, writer, DictReader, DictWriter 함수 사용법을 배웠다.
- 안좋은 프로그래밍 습관을 고쳤다(자세한건 개발 일지에 있다.)

## 사용한 기술 스택
- Python 3.14.3

## 프로젝트 구조
```
project/
├── development-log.md # 개발 일지
├── main.py # 소스코드
├── household-account.csv # 가계부 저장 파일
└── README.md
```

## 어떻게 실행하는가
cmd에서 `python main.py`를 실행한다.

## 아쉬운 점 / 다음에 해보고 싶은 것
- 함수 분리를 제대로 하고 싶다.
- 다음 프로젝트부터는 csv보단 sql을 사용해보고 싶다.
- 나는 항목 삭제를 하면 그 뒤에 있는 항목들의 id를 재넘버링 해줬는데 실제로는 그냥 고윳값처럼 냅둔다고 한다.
- total 값을 매 행에 저장하기 보다는 필요할 때 계산하는게 안전하다고 한다.
- 파일을 통째로 열어서 'w'로 덮어쓰는 방식보다는 임시 파일을 만들어서 거기에 쓰고 os.replace 함수로 원본 이름으로 교체하는게 안전하다. 기존 방법이라면 파일을 쓰다가 꺼졌을 때 나머지 모든 내용이 사라진다.
- 나는 컬럼을 대괄호로 많이 불러왔는데 실무에서는 csv.DictReader, csv.DictWriter로 이름 기반 접근을 하는게 좋다.
- 타입 힌트는 실무에서 거의 기본이지만 나는 하나도 사용하지 않았다.
